# Pol brand

The mark is two Persian commas («،») in the style of [Virgule](https://virgule.studio)'s logo, facing each other so
their tails meet in an arch: a bridge (*pol*) between two phones. Virgule's red square sits under the arch, on the
baseline.

| Colour | Hex | Use |
|---|---|---|
| Virgule blue | `#3A4CC0` | App icon background, brand accent |
| Virgule red | `#E0522F` | The square, always |
| Ink | `#1B1B1B` | Mark on light backgrounds |
| Cream | `#F4F2EE` | Light background |

Files: `pol-icon.svg` (app icon), `pol-icon-light.svg`, `pol-icon-dark.svg`, `pol-mark.svg` (mark only) and
`pol-icon-1024.png`. The Android launcher icon (`android/app/src/main/res/drawable/ic_launcher_*.xml`) and the iOS app
icon (`ios/Pol/Resources/Assets.xcassets/AppIcon.appiconset`) use the same path.
