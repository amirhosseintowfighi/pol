# Pol brand

The mark is a bridge (*pol*) with a single arch, the sun setting through it over the water, drawn in the geometric
language of [Virgule](https://virgule.studio): flat shapes, a few thin lines, Virgule blue, mustard and the red square.
The bridge joins two banks the way Pol joins two phones.

| Colour | Hex | Use |
|---|---|---|
| Virgule blue | `#3A4CC0` | The bridge and the water, brand accent |
| Mustard | `#E8B13E` | The sun |
| Virgule red | `#E0522F` | The square, always |
| Ink | `#1B1B1B` | Dark variant background |
| Cream | `#F4F2EE` | App icon background |

Files: `pol-icon.svg` (app icon), `pol-icon-light.svg`, `pol-icon-dark.svg`, `pol-mark.svg` (mark only) and
`pol-icon-1024.png`. The Android launcher icon (`android/app/src/main/res/drawable/ic_launcher_*.xml`) and the iOS app
icon (`ios/Pol/Resources/Assets.xcassets/AppIcon.appiconset`) are drawn from the same shapes.
